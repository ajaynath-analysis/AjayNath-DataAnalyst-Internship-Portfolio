## Key Findings

- Manhattan has the highest number of Airbnb listings.
- Entire Home/Apt is the most common room type.
- Entire Home/Apt has the highest average price.
- Availability varies significantly across boroughs.
- Most listings belong to the medium-price category.
- Price and availability show a weak relationship.
